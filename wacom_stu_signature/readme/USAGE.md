1. Open a delivery order and click its signature field (or the *Sign* button).
2. The dialog connects to the pad and shows a signing prompt on its screen,
   with the name of the signer when the field defines one.
3. The customer signs on the pad. The strokes appear in Odoo in real time.
4. Click **Accept** to store the signature, **Clear** to start again, or
   **Sign with the mouse** to use Odoo's standard dialog instead.
